# LingoBee — Landing Page Context

Use this document as the complete reference for building the LingoBee landing page.

## App Overview

**LingoBee** is a kids' English learning app for ages 2-5. Children learn English vocabulary through interactive games — flashcards, quizzes, matching, and pronunciation practice. The app teaches English words with translations in Uzbek and Russian.

- **Package ID:** `com.summerapps.lingobee`
- **Developer:** Khamidjon Egamov
- **Target audience:** Toddlers and preschoolers (2-5 years old)
- **Target markets:** Uzbekistan and Russian-speaking countries
- **Platform:** iOS (App Store)

## Tagline Ideas

- "Learn English, one word at a time!"
- "English for little learners"
- "Fun English words for kids 2-5"

## Key Features (for feature section)

1. **15 Learning Categories** — Animals, Numbers, Colors, Shapes, Fruits, Body Parts, Food, Vehicles, Weather, Clothes, Family, House, School, Nature, Emotions
2. **4 Game Modes** — Flashcards, Quiz, Matching, Pronunciation practice
3. **3 Languages** — English words with Uzbek and Russian translations
4. **Text-to-Speech** — Native English pronunciation for every word
5. **Progress Tracking** — Stars (0-3) per game, visual progress for parents
6. **Daily Streak** — Encourages daily practice habit
7. **No Ads** — Safe, distraction-free environment for kids
8. **Offline Ready** — All content works without internet

## Game Modes (detail)

| Mode | Description | How it works |
|------|-------------|--------------|
| Flashcards | Swipe through word cards | See emoji + word, hear pronunciation via TTS |
| Quiz | Multiple choice questions | Pick the correct word from 4 options |
| Matching | Match words to emojis | Drag-and-drop or tap to pair words with pictures |
| Pronunciation | Hear and practice speaking | Listen to the word, practice saying it |
